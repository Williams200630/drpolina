# Вояж — пять ночей, обновлённая версия

Откройте `index.html` в браузере. Интернет и установка библиотек для игры не нужны. Для разработки можно запустить `python -m http.server 4182` и открыть http://127.0.0.1:4182.

Изменения:
- Время продвигается по сюжету, а не реальному таймеру. После первого посетителя — 02:00, после всех дел — 04:00, после второго — 05:00, после третьего — 06:00. Пока дела не завершены, рассвет не наступит.
- Ровно три посетителя в каждой из пяти ночей. Пятая ночь также содержит очередь; ячейка №0 закрыта до её завершения.
- Четвёртая комната — архив невостребованных. По два новых механизма на ночь, всего десять. Решение начинается с прочтения записки. Второй механизм открывается после первого.
- Новые лица с тенями, глазами и разными чертами. У части нечеловеческих посетителей неестественные улыбки и зубы; другие распознаются по документам.
- Фактура, освещение, виньетка, детали помещений и обновлённый интерфейс.
- Фоновый гул ламп, треск при мерцании и синтезированный крик скримера. В меню есть кнопки проверки звуков. «Хватит» отключает эффекты, доступны мягкий режим и выключение звука.
- Граммофон использует предоставленный пользователем MP3 `audio/family-tune.mp3`. Звук активируется после нажатия в игре; кнопка выключения звука также останавливает музыку.

Файлы: `index.html` — исходная игра и предметные цепочки; `upgrade.js` — сюжетное время, архив, портреты и звук; `upgrade.css` — оформление; `audio/` — музыка; `GUIDE.md` — ответы; `test-story.cjs` — проверки пяти ночей и десяти механизмов.

Проверки: `node test-story.cjs` (87 проверок). В браузере пройдена первая ночь вместе с двумя новыми загадками и тремя посетителями: 06:00 наступило после третьего посетителя без ожидания таймера.

Сохранения хранятся в браузере. Старые сохранения совместимы, но новые архивные механизмы текущей ночи нужно пройти. Для проверки всей истории начните заново через меню.

Подсказки: сверху только ночь, время и страйки. Кнопка «Застряла?» показывает один следующий шаг с учётом текущей комнаты. После действия подсказка скрывается.

Финал: отдельный светлый экран, SVG-торт и 20 свечей с последовательным зажиганием. Задувание по микрофону (только после нажатия и разрешения браузера) или кнопкой. Звук анализируется локально, без записи и отправки. Проверка микрофонного алгоритма выполнена синтетическим сигналом; реальный микрофон не включался при QA.
Пять ночей дают пять карточек: их можно посмотреть через инвентарь и собрать в письмо после задувания свечей. Золотая карточка из фотографии добавляет отдельный абзац. Старые сохранения получают карточки уже пройденных ночей автоматически.
